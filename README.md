# 논술형 평가 문항 설계

「2025 중등 논술형 평가 길라잡이」(경기도교육청) 방법론과 2022 개정 교육과정을 반영한,
성취기준과 수업 자료를 바탕으로 문항, 채점기준, 피드백 예시를 설계하는 교사용 웹앱입니다.

정적 파일로 배포할 수 있으며 React와 JSZip은 `vendor/`에서 불러옵니다. 원본 UI는 `app.jsx`,
배포용 스크립트는 esbuild로 만든 `app.js`입니다.

## 실행 방식 두 가지

상단 **작업 방식**에서 선택합니다.

1. **Claude에 요청문 붙여넣기** — 기본값.
   앱이 입력 양식을 바탕으로 요청문을 만듭니다. 요청문을 **Claude**(Claude
   Pro/Max 구독)에 붙여넣고, Claude가 출력한 결과(JSON)를 다시 앱에 붙여넣으면 문항·루브릭·모범답안이
   표 형태로 정리됩니다. **API 키가 필요 없습니다.**
   - 참고: Claude Pro/Max 구독은 API 접근권이 아닙니다. 제3자 웹앱이 구독으로 Claude를 직접
     호출할 수 있는 공식적 방법은 없으므로, 생성은 claude.ai에서 하고 앱은 프롬프트 작성·결과
     정리를 맡는 이 방식이 구독을 활용하는 정당한 경로입니다.
2. **Gemini API로 바로 만들기** — 개인 Gemini API 키를 넣으면 앱 안에서 평가 문서를 만듭니다.

## 주요 기능

**입력·변환**
- 성취기준 선택 → 출제 자료 준비 → 문항 설계 → 생성·검토의 4단계 작업 흐름과 단계별 완료 요약
- 공식 성취기준 선택과 직접 입력을 분리하고, 선택한 공식 기준은 칩과 공식 성취수준으로 확인
- 성취기준으로 새 문항 만들기 / 기존 지필 문항을 논술형으로 바꾸기 / 자료 제시형 면접을 단계형 논술 문항으로 바꾸기 / 기존 논술형 문항 변형하기 / 주제·아이디어로 만들기
- 글·사진·PDF 동시 입력(자료 속 문항·제시문·표·그림을 읽어 반영)
- 정책브리핑·국가법령정보센터·KOSIS·ScienceON·국회도서관을 정보원별로 검색하고, 선택 자료의 제공 기관·원자료명·날짜·원문 URL을 결과 문서에 기록
- 검색어와 관련 없는 정책뉴스는 대체 결과로 표시하지 않으며, 결과가 없으면 확장 검색어와 다른 정보원을 안내
- 입력 자료에 맞는 출제 패턴 3개와 추천 이유 제시, 추천 패턴 또는 전체 목록에서 직접 선택
- 출제 패턴 7종: 공통 개념 추론·전이 / 기제 설명·조건 예측 / 자료 해석·주장 평가 / 문제 진단·해결 설계 / 실험 분석·개선 설계 / 비교·통합 논증 / 쟁점 판단·의사결정
- 자료 구성(복수 제시문·대립 자료·영역 융합·표·그래프·실험·실제 사례 등)을 출제 패턴과 분리해 설정
- 그림자료(SVG 도식) 자동/항상/안 함 선택

**교육과정 정합성**
- 길라잡이 방법론(발문·자료·조건, 반응 지시어 17종, 평가요소 '~하기', 채점기준표 원칙)을 시스템 지침으로 내장
- 2022 개정 과학과 성취기준 체계 반영, 2015 개정 혼용 자동 판별·안내 배지
- 대상 과목 선택 시 위계 통제로 상위 학년·심화 개념 배제(선행학습 방지)

**평가 설계**
- 문항별 모범답안(A수준), 자료–발문 연계 표기
- 성취수준 A~E, 채점기준표 5단계
- 목표 성취수준에 따른 변별 설계와 수준 설계 해설(내용요소 분석·적합성 근거)
- 모든 논술형 문항에 GRASPS의 목표(Goal)·산출물(Product)·평가기준(Standards)을 기본 적용하고 상황·역할·독자를 선택적으로 추가
- 결과 문서에 적용한 출제 패턴, 사고 단계, 자료 구성, 핵심 사고행위와 GRASPS 수행 맥락 기록

**출력**
- 교사용/학생 배부본 전환, Word 다운로드, HWP·Word용 복사
- AI 초안 → 교사 검토 완료 → 최종 승인 상태 관리, 검토 체크리스트, 부분 수정 요청, 이전 버전 복원
- 모바일에서 생성 완료 후 첫 문항으로 자동 이동하고 설정·결과별 스크롤 위치를 보존
- 학생용 발문은 문서 폭에 맞춰 조판하고, 빈 조건 범주와 글자 수·분량만 지정하는 형식 조건은 화면·인쇄·Word에서 제외

## 사용 방법

공통: 과목 → 목표 성취수준 → 설계 방식 → 출제 자료 → 추천 출제 패턴 → 문항 구성을 설정합니다.

**A. Claude에 요청문 붙여넣기**
1. **Claude용 요청문 복사**를 누릅니다.
2. [Claude](https://claude.ai)에 로그인해 새 대화에 붙여넣습니다.
   사진을 넣었다면 그 대화에 이미지도 함께 첨부하세요.
3. Claude가 출력한 결과 전체(중괄호 `{ }` 포함)를 복사합니다.
4. 앱의 **Claude 답변** 칸에 넣고 **결과 확인**을 누릅니다.

**B. Gemini API 모드**
1. **Gemini API 키 발급**: [aistudio.google.com](https://aistudio.google.com) → Get API key
   (카드 등록 불필요). `AIza…`로 시작하는 키를 복사합니다.
2. 앱 상단 **문항 생성 방식 → 이 앱에서 바로 만들기**를 고르고 키를 붙여넣습니다.
   - 키는 본인 브라우저(localStorage)에 저장되며 Google Gemini API 호출에 사용됩니다. 앱 서버에는 저장되지 않습니다.
   - 모델 기본값은 `gemini-2.0-flash`이며, 연결된 키에서 사용 가능한 모델을 조회해 바꿀 수 있습니다.
3. **평가 문서 만들기**를 누릅니다.

## GitHub Pages로 배포하기 (터미널 불필요)

1. 이 저장소의 **Settings → Pages**로 이동합니다.
2. **Source**를 `Deploy from a branch`로, 브랜치를 배포할 브랜치(예: `main`)와 `/ (root)`로 지정하고 저장합니다.
3. 몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속하면 됩니다.

## 주의사항

- **API 키는 절대 코드에 적거나 커밋하지 마세요.** 이 앱은 키를 코드에 저장하지 않고 실행 시 입력받습니다.
- 공공 자료 API 키도 저장소에 넣지 말고 Vercel 프로젝트의 Environment Variables에만 등록하세요. 사용 변수는 `POLICY_BRIEFING_API_KEY`, `MOLEG_API_KEY`, `KOSIS_API_KEY`, `NANET_API_KEY`, `SCIENCEON_API_KEY`입니다. ScienceON은 API Gateway 활용신청 후 승인 화면에 표시되는 요청 URL·파라미터 규격을 별도로 연결해야 합니다. 고정 IP 같은 추가 조건은 계정의 승인 내용에 명시된 경우에만 적용됩니다.
- 공개 페이지로 배포해도 키는 코드에 없으므로, Gemini 모드 방문자는 각자 자기 키를 입력해야 동작합니다.
- 생성 결과(성취수준 추정·위계·SVG 도식)는 LLM 특성상 편차가 있을 수 있으니 출제 전 한 번 검토하세요.
- 성취수준 기술을 함께 입력할수록 수준 설계 해설의 정확도가 올라갑니다.

## 구조

- `index.html` — 마크업, 디자인 토큰, 화면·인쇄 CSS, 정적 스크립트 로드
- `app.jsx` — React 원본, UI, 요청문 조립, API 호출, 결과 렌더링
- `app.js` — esbuild로 생성한 배포용 스크립트
- `standards-data.js` — 2022 개정 과학과 성취기준·성취수준 데이터
- `vendor/` — 셀프호스팅 라이브러리

## 개발 (코드 수정 방법)

앱 소스는 `app.jsx`(JSX 원본)이며, 배포는 컴파일된 `app.js`를 정적으로 서빙합니다.
`app.jsx`를 수정한 뒤 반드시 아래 명령으로 `app.js`를 다시 생성해 **함께 커밋**하세요:

```bash
npx esbuild app.jsx --loader:.jsx=jsx --minify --charset=utf8 --outfile=app.js
```

- `index.html` — 마크업·스타일·스크립트 로드 (브라우저 내 Babel 컴파일 제거됨)
- `vendor/` — React 18.3.1 · ReactDOM 18.3.1 · JSZip 3.10.1 셀프호스팅 (CDN 미의존)
- `standards-data.js` — 2022 개정 과학과 성취기준·성취수준 데이터 (엑셀에서 자동 생성)
- `api/source-search.js` — 공공 자료 정보원 통합 검색 프록시 (Vercel 서버리스, 환경변수 필요)
- `vercel.json` — 정적 배포 설정 + CSP 등 보안 헤더
