# SAMPLE_DATA — 테스트·시연용 샘플 응답

기능 검증과 시연을 쉽게 하기 위한 예시 응답 모음입니다. 실제 저장은 하지 않으며,
학생 화면에 붙여넣어 교사 대시보드·리뷰 흐름을 시연할 때 사용합니다.

| 학생 | 용도 |
|------|------|
| S-001 | 우수 답안 |
| S-002 | 보통 답안 |
| S-003 | 목적론 오개념 답안 |
| S-004 | 자료 해석 우수 답안 |
| S-005 | AI 비판 피상적 답안 |

---

## S-001 / B2 — 우수 답안

```text
1세대에서 밝은 몸색 개체가 80%였지만 15세대에는 25%로 줄고 어두운 몸색이 75%로 늘었다.
환경 배경이 어두워지면서 어두운 몸색 개체가 더 잘 생존·번식했다고 볼 수 있다.
이는 개체 하나가 스스로 색을 바꾼 것이 아니라, 개체군 안에 이미 있던 변이 중
어두운 형질이 자연선택되어 형질 빈도가 세대에 걸쳐 변한 것이다.
다만 생존율·번식률 자료가 없으므로 자연선택을 단정하려면 추가 자료가 필요하다.
```

예상 루브릭: 개념 정확성 4 / 자료 해석 4 / 논증 구조 3~4
예상 오개념: 없음

---

## S-002 / B2 — 보통 답안

```text
어두운 환경에서는 어두운 곤충이 더 많아졌다.
자료를 보면 어두운 몸색 비율이 20%에서 75%로 늘었다.
자연선택으로 어두운 색이 살아남았다.
```

예상 루브릭: 개념 정확성 3 / 자료 해석 3 / 논증 구조 2~3
예상 오개념: 변이 누락(개체군 안 변이 언급 없음)

---

## S-003 / B2 — 목적론 오개념 답안

```text
곤충은 어두운 환경에서 살아남기 위해 몸 색깔을 어둡게 바꾸었다.
그래서 어두운 곤충이 많아졌다.
생물은 필요하면 환경에 맞게 변한다.
이것이 진화이다.
```

예상 오개념:
- 목적론 (필요해서 생겼다)
- 개체 변화 (개체가 스스로 변했다)
- 환경 결정론 (환경 변화만으로 설명)

---

## S-004 / B1 — 자료 해석 우수 답안

```text
밝은 몸색 비율은 1세대 80%에서 15세대 25%로 감소하고, 어두운 몸색은 20%에서 75%로 증가한다.
환경 배경도 밝음에서 어두움으로 변한다.
그러나 표에는 생존율, 번식률, 형질 유전 여부, 다른 환경 요인이 제시되지 않았다.
따라서 몸색 변화가 자연선택 때문이라고 단정할 수 없고,
이를 주장하려면 생존율·번식률 같은 추가 자료가 필요하다.
```

예상 루브릭: 자료 해석 4 / 비판적 검증 4
예상 오개념: 없음

---

## S-005 / D1 — AI 비판 피상적 답안

```text
AI가 틀릴 수도 있어서 위험하다.
그래서 AI를 너무 믿으면 안 된다.
```

예상 오개념: AI 비판 피상적 (어떤 데이터가 부족·편향될 때 어떤 오류가 생기는지 구체성 없음)
예상 피드백: 특정 지역·생물군 자료 부족이 분류 결과를 어떻게 왜곡하는지 구체적으로 쓰도록 안내.
