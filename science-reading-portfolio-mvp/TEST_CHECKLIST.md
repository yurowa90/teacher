# TEST_CHECKLIST — 과학 독서·논술 포트폴리오 (Stage 1.1)

자동 검증 스크립트(헤드리스 브라우저)로도 22개 항목 통과를 확인했다.

## CSV 수동 검증(권장)

실제 브라우저에서 CSV를 내려받아 Excel/Google Sheets로 열어 확인한다.

| 검증 항목 | 기준 |
|-----------|------|
| 한글 깨짐 | 정상 표시(UTF-8 BOM) |
| 줄바꿈 답안 | 한 셀 안에 유지 |
| 쉼표 포함 답안 | CSV 구조 유지(따옴표 이스케이프) |
| 루브릭 점수 | 기준별 열에 들어감 |
| 오개념 태그 | 한 셀에 ` / ` 구분 |
| 피드백 | 누락 없이 들어감 |

## 회귀 테스트 실행(개발자용)

헤드리스 브라우저 스크립트로 위 기능 테스트를 반복 실행할 수 있다.
(Playwright로 `index.html`을 `file://`로 로드해 각 시나리오를 구동.)
