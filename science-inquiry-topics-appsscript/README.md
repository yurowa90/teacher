# 칼럼을 통해 탐구활동 주제 찾기 — Google Apps Script

공유해 주신 "칼럼 → 탐구활동 주제" 도구와 **같은 구조**를 과학 독서·논술용으로 재현한 앱입니다.
외부에서 모은 **칼럼(기사)** 목록을 구글 시트에 쌓아두고, 기사마다 **핵심주제·핵심키워드·분야별
탐구 질문**을 붙여 웹앱에서 검색·필터·복사할 수 있습니다.

- 외부 자료(칼럼)를 가져오고 → 그 자료에 대한 탐구 질문이 제시되는 구조
- 앱·데이터가 같은 출처(Apps Script) → CORS/CSP 문제 없음
- 학생·교사용 **아이디어 발견 도구**(세특 탐구 주제·독서논술 발문 활용)

## 화면 구성 (원본과 동일)

- 상단 브랜드 패널 + 이용 안내
- **필터**: 검색어 · 분야(학과) 선택 · 업데이트 기간 · 보기 방식(20/50/80/전체)
- **통계 카드**: 검색 결과 · 관련 기사 · 연결 분야 · 최근 업데이트
- **기사 카드**: 출처 | 매체 | 날짜 · 분야 배지 · 제목 · 핵심주제 · 핵심키워드 칩 · 분야별 탐구 질문(1·2·3) + **복사** 버튼

## 파일

| 파일 | 역할 |
|------|------|
| `Code.gs` | `doGet`(웹앱 서빙), `getArticles`(시트 읽기+통계), `setupSheets`(Articles 탭·샘플 생성) |
| `Index.html` | 브라우저 UI(검색/필터/통계/기사 카드/복사) — `google.script.run` 호출 |
| `appsscript.json` | 매니페스트 |
| `SHEET_TEMPLATE.md` | Articles 시트 열 구조 |

## 설치

1. 새 구글 시트 → **확장 프로그램 → Apps Script**
2. `Code.gs` 붙여넣기, HTML 파일 `Index` 만들어 `Index.html` 붙여넣기
3. **`setupSheets`** 실행 → `Articles` 탭 + 과학 칼럼 샘플 생성
4. **배포 → 웹 앱** → 실행: 나 / 액세스: 원하는 범위 → URL 공유

## 자료 채우기 (자동 업데이트 연결)

- `Articles` 시트에 **한 행 = (기사 × 분야)** 로 칼럼을 쌓습니다(열 구조는 `SHEET_TEMPLATE.md`).
- 매주 자동으로 채우려면, 별도 스크립트(RSS·뉴스 수집 등)나 기존에 쓰시던 수집 스크립트가
  이 `Articles` 시트에 같은 열 이름으로 append 하도록 하면 됩니다. 이 앱은 조회·질문 제공만 담당합니다.
- 이미 운영 중인 피드(예: `script.google.com/...` 웹앱)가 있다면, 그 스크립트가 만드는 데이터를
  이 시트 스키마에 맞춰 쓰거나, `getArticles` 파서를 기존 데이터 형태에 맞게 바꿔 연결할 수 있습니다.

## 참고

- 샘플 칼럼(유전자 편집·기후 데이터·생물다양성 등)은 예시이며, 실제 칼럼으로 자유롭게 교체하세요.
- 탐구 질문은 시트에 미리 작성해 둔 것을 그대로 제시합니다(AI 자동 생성 아님 — 교사가 검토·관리).
