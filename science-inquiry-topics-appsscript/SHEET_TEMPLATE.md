# Articles 시트 구조

`setupSheets` 실행 시 `Articles` 탭이 생성됩니다. **한 행 = (기사 × 분야)** 입니다.
같은 칼럼이 여러 분야에 걸리면, 제목·핵심주제는 같게 두고 `department`·`questions`만 다른
여러 행으로 추가하세요(원본 도구처럼 같은 기사가 분야별 카드로 반복 표시됩니다).

## 열

| 열 | 설명 | 예시 |
|----|------|------|
| `id` | 행 식별자(자유) | c1 |
| `date` | 업데이트 날짜(YYYY-MM-DD) — 기간 필터·최근 업데이트에 사용 | 2026-07-05 |
| `source` | 매체 | 한겨레 |
| `via` | 플랫폼 | 네이버 |
| `title` | 칼럼 제목 | 유전자 가위 시대, 우리는 어디까지… |
| `coreTheme` | 핵심주제 요약 | 크리스퍼 유전자 편집과 생명윤리의 경계를 탐색한다. |
| `keywords` | 핵심키워드(쉼표 구분) — 칩으로 표시 | 유전자 편집, 크리스퍼, 생명윤리, 규제 |
| `department` | 분야(학과) — 필터·배지에 사용 | 생명과학 분야 |
| `fieldKeywords` | 분야별 강조 키워드(자유 텍스트) | 유전자 편집, 생명윤리, 규제 |
| `questions` | 탐구 질문 — **줄바꿈(엔터)으로 여러 개** | (아래) |

### questions 예시 (한 셀에 줄바꿈으로 여러 질문)

```
배아 편집이 허용될 경우 치료와 개량의 경계를 어떻게 구분할까?
오프타깃 문제를 줄이는 최근 연구 동향을 조사해 보자.
국가별 규제 입장을 비교하고 사회적 합의 방안을 논술해 보자.
```

> 셀 안에서 줄바꿈은 `Alt+Enter`(윈도우) / `Option+Enter`(맥)로 입력합니다.

## 필터·통계 동작

- **검색어**: 제목·핵심주제·키워드·분야·질문 전체에서 부분 일치 검색
- **분야(학과) 선택**: `department` 값으로 필터. 옵션은 시트의 분야에서 자동 생성
- **업데이트 기간**: `date` 값으로 필터. 옵션은 시트의 날짜에서 자동 생성(최신순)
- **보기 방식**: 표시 개수 제한(20/50/80/전체)
- **통계 카드**: 검색 결과(표시 수) · 관련 기사(전체 행) · 연결 분야(고유 분야 수) · 최근 업데이트(최신 날짜)
