# 과학 독서·논술 포트폴리오 — Google Apps Script 버전

**구글 시트(자료 + 질문) → Apps Script가 웹앱까지 같은 출처에서 서빙**하는 구조입니다.
교사는 구글 시트만 편집하면 자료·활동·루브릭·오개념이 앱에 반영되고, 학생 답안과
교사 리뷰는 다시 시트에 저장되어 누적됩니다.

- 외부에서 자료를 가져오고(구글 시트) 그 자료에 대한 활동(질문)이 구성되는 구조
- 앱과 데이터가 같은 출처(Apps Script) → **CORS/CSP 문제 없음**
- 로그인 강제·외부 AI·자동채점 없음 · 실명·학번 미수집 · 교사가 최종 평가자

## 파일

| 파일 | 역할 |
|------|------|
| `Code.gs` | 서버: `doGet`(웹앱 서빙), 시트 읽기(`getModule`/`getBootstrap`), 저장(`saveResponse`/`saveReview`), `setupSheets`(초기 탭·샘플 생성) |
| `Index.html` | 클라이언트 웹앱(학생 화면 / 교사 대시보드). `google.script.run`으로 서버 호출 |
| `appsscript.json` | 매니페스트(웹앱 접근 권한·스코프) |
| `SHEET_TEMPLATE.md` | 구글 시트 탭·열 구조 설명 |

## 설치 (약 5분)

1. **새 구글 시트**를 만든다.
2. 상단 메뉴 **확장 프로그램 → Apps Script**.
3. 기본 `Code.gs` 내용을 지우고 이 폴더의 **`Code.gs`** 내용을 붙여넣는다.
4. 왼쪽 **파일 +** → **HTML** → 이름을 `Index`로 하고, 이 폴더의 **`Index.html`** 내용을 붙여넣는다.
   (파일명이 정확히 `Index` 여야 `doGet`이 찾는다.)
5. (선택) 매니페스트를 맞추려면 톱니바퀴 **프로젝트 설정 → "appsscript.json" 매니페스트 파일 표시**를 켜고
   `appsscript.json` 내용을 붙여넣는다.
6. 상단 함수 선택에서 **`setupSheets`** 를 고르고 **실행**한다. 권한 승인 후 시트에
   `Module`, `Activities`, `Rubric`, `Misconceptions`, `Students`, `Responses`, `Reviews` 탭이 생긴다.
7. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: 학생에게 공유할 범위 선택(예: *링크가 있는 모든 사용자* 또는 *도메인 내 사용자*)
   - **배포** → 나오는 **웹 앱 URL**을 학생·교사에게 공유한다.

> 이미 쓰던 시트/스크립트가 있다면, `setupSheets`가 **없는 탭만** 새로 만들고 기존 탭은 건드리지 않는다.
> 열 이름만 `SHEET_TEMPLATE.md`에 맞추면 기존 데이터를 그대로 쓸 수 있다.

## 교사 사용법

- 시트의 **`Module`** 탭에서 책·과목·성취기준·단원 제목·소개를 입력한다.
- **`Activities`** 탭에서 활동(질문)을 자유롭게 추가/수정한다: `code, level, type, title, prompt, resource`.
  - `resource` 열에 자료 표를 넣으려면 JSON을 붙여넣는다(형식은 `SHEET_TEMPLATE.md` 참고). 일반 텍스트도 가능.
- **`Rubric`**, **`Misconceptions`** 탭에서 채점 기준·오개념을 관리한다.
- 웹앱 **교사 대시보드**에서 진행률·제출률·오개념 빈도를 보고, 셀을 눌러 답안을 채점·피드백한다.
- 시트를 수정한 뒤 대시보드의 **시트에서 새로고침** 버튼으로 다시 불러온다.

## 학생 사용법

- 공유받은 웹 앱 URL을 연다.
- 상단에서 **익명 ID**(S-001 등)를 고르고 활동에 답을 작성한다. 입력하면 자동으로 시트에 저장된다.

## 데이터·개인정보

- 학생 식별은 **익명 라벨(S-001 …)만** 사용한다. 실명·학번 열은 없다.
- 답안은 `Responses`, 리뷰는 `Reviews` 탭에 `(studentId, code)` 단위로 upsert 저장된다.
- 동시 저장 충돌은 `LockService`로 보호한다.

## 제한

- 학생이 익명 ID를 스스로 고르는 방식이라, 같은 반에서 라벨 중복을 피하도록 안내가 필요하다.
  (더 엄격한 인증·계정 분리는 Supabase 서버 버전 `science-reading-portfolio-server/` 참고.)
- AI 자동채점·세특 자동 작성은 제공하지 않는다(교사가 최종 판단).
