# 책갈피 — Google Apps Script 간소화 버전

Vercel/Supabase 없이 **구글 계정만으로** 돌리는 간소화 버전입니다.
데이터는 **구글 시트**(자동 생성), 로그인은 **구글 계정**을 씁니다.

> 이 버전 기능: 학급 만들기·참여, 도서 등록·삭제, **문장 수집(교사·학생 모두)**,
> **질문·토론 게시판(질문 올리기 + 서로 댓글)**, 교사의 학생 기록 열람,
> 모든 기록 **구글 시트 자동 저장** + 교사용 "스프레드시트 열기" 버튼.
> 서평 게시승인·갤러리·좋아요/별점·우수작·포스터 업로드·통계는 **웹(Vercel) 버전에만** 있습니다.

## 만드는 법 (5분)

1. **script.google.com** 접속 → **새 프로젝트**
2. 왼쪽 파일 목록에서:
   - 기본 `Code.gs` 내용을 지우고 → 이 폴더의 **`Code.gs`** 내용을 붙여넣기
   - **＋ → HTML** 로 파일 추가, 이름을 정확히 **`index`** 로 → 이 폴더의 **`index.html`** 내용을 붙여넣기
3. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - **실행 계정: 나**
   - **액세스 권한:** 학교 구성원(같은 Google Workspace) 또는 "Google 계정이 있는 모든 사용자"
   - **배포** → 권한 승인(처음 한 번) → **웹 앱 URL** 복사
4. 그 URL을 학생·교사에게 공유하면 끝!

## 중요: 로그인(계정 인식)에 대해

이 앱은 접속한 사람의 **구글 이메일**로 신원을 확인합니다.
- **학교 Google Workspace 계정**(예: `이름@학교.kr`)으로 같은 도메인 안에서 쓰면 이메일이 잘 읽혀
  학급·문장이 사람별로 정확히 구분됩니다. **← 권장 사용 환경**
- 개인 Gmail 등 **도메인이 다른 계정**은 Apps Script 특성상 이메일이 비어 올 수 있어,
  "계정 확인 필요" 안내가 뜰 수 있습니다.

## 사용 흐름

- **교사**: "학급 만들기" → 참여코드 확인 → 학생에게 공유 → 도서 등록 → 학생 문장 열람
- **학생**: "학급 참여"(코드 입력) → 문장 수집 → 질문·토론(질문 올리고 친구 질문에 댓글)

## 데이터는 어디에?

처음 실행하면 내 구글 드라이브에 **"책갈피 데이터 (독서교육 앱)"** 시트가 자동 생성됩니다.
탭(Classes/Members/Books/Sentences)에 자료가 쌓입니다. 이 시트를 지우면 데이터가 사라집니다.
